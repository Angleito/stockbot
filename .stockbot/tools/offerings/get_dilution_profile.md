# get_dilution_profile

Domain: offerings

Deterministic dilution math for diluted shareholders: inputs, formula, and source accessions always shown.

## Use when

- Quantifying how diluted shareholders could get: share-count impact, dilution picture, from offerings, converts, or warrants.

## Avoid when

- Do not use for offering terms history; use get_offering_history instead.

## Related tools

- get_offering_history

## Prerequisites

None

## Required arguments

- `ticker` (string)

## Optional arguments

- `as_of` (string)
